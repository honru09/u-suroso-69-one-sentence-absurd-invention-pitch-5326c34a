## What it does

`main.py` (Python standard library only) writes a single sentence pitching a ridiculous invention that fixes a tiny everyday annoyance to `/output/entry.txt` — one sentence, 142 characters, deterministic on every run.

The pitch: a door hinge that cures its own squeak by crying a single tear of lubricant every time the door opens, keeping the house silent and faintly haunted.

## Run

```sh
python3 main.py
```

It creates `/output` if missing, clears its contents, writes `/output/entry.txt` (one line plus a trailing newline, mode 0644), and validates the sentence first: exactly one sentence, 1–220 characters, not only whitespace.
